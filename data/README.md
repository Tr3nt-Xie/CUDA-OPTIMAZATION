# 共用数据（A 负责）

- `fixtures/`：可提交的小型正确性输入/期望输出，包括非整块矩阵与非对称卷积滤波器。
- `generated/`：可再生的大型正式输入，Git 忽略；由全组同一生成脚本产生。
- 数据 manifest 要记录文件、shape、dtype、字节序、生成方法/种子、SHA-256 和 filter_id。
- 实验使用的 manifest 副本随对应 results/raw/<run_id>/ 记录提交，从而能核对被忽略的实际输入。
- 展示图片注明来源；保存原图及滤波参数，展示处理不改变用于校验的原始浮点输出。

当前目录尚无实验数据；由 A 先交付小样例，再生成统一正式输入。
